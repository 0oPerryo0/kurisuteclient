# クリステの遺宝 Desktop

Unofficial Windows client for the [DMM game page](https://games.dmm.co.jp/detail/charsapple_x_879635). It does not include the game. Log in on DMM's own pages. You must meet the site's age requirements.


- Game-only view with uniform scaling
- Ambient background sampled from the game edges
- Fullscreen
- Mute
- Always on top
- Zoom
- FPS cap
- Speed control
- Screenshot
- Optional DMM region-cookie override (on by default; toggle in right-click menu)
- Optional game language (experimental, off by default): right-click → Game language. Switches the game to its built-in Simplified Chinese text by changing the startup language setting in the locally loaded game data. 繁體中文（台灣） converts menus and other UI text to Taiwan Traditional Chinese with [OpenCC](https://github.com/nk2028/opencc-js), using only characters the game's font can draw; story dialogue stays in the original Simplified Chinese. 日本語 loads the unmodified game.
